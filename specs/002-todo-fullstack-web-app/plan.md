# Implementation Plan: Todo Full-Stack Web Application (Phase II)

**Branch**: `002-todo-fullstack-web-app` | **Date**: 2025-12-25 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/002-todo-fullstack-web-app/spec.md`

## Summary

Transform the Phase I console-based Todo application into a multi-user full-stack web application with:
- **Frontend**: Next.js 14+ (App Router) with TypeScript and Tailwind CSS
- **Backend**: FastAPI with SQLModel ORM
- **Database**: Neon Serverless PostgreSQL
- **Authentication**: Better Auth with JWT (7-day expiry)
- **Architecture**: RESTful API with user-scoped task ownership

---

## Technical Context

**Language/Version**: Python 3.11+ (Backend), TypeScript (Frontend)
**Primary Dependencies**: FastAPI, SQLModel, Next.js 14+, Tailwind CSS, Better Auth
**Storage**: Neon Serverless PostgreSQL
**Testing**: pytest (Backend), Vitest + React Testing Library (Frontend)
**Target Platform**: Web browsers (Chrome, Firefox, Safari, Edge - last 2 versions)
**Project Type**: Web application (frontend + backend)
**Performance Goals**: <3s page load, <2s task operations, 100 tasks per user typical
**Constraints**: Stateless backend, 7-day token expiry, ownership enforcement
**Scale/Scope**: Multi-user application, ~1000 users initial target

## API Endpoints Summary

| Method | Endpoint | Description | Auth |
|--------|----------|-------------|------|
| POST | `/api/auth/register` | Register new user | No |
| POST | `/api/auth/login` | Login user | No |
| POST | `/api/auth/logout` | Logout user | Yes |
| GET | `/api/auth/me` | Get current user | Yes |
| GET | `/api/{user_id}/tasks` | List tasks | Yes |
| POST | `/api/{user_id}/tasks` | Create task | Yes |
| GET | `/api/{user_id}/tasks/{id}` | Get task | Yes |
| PUT | `/api/{user_id}/tasks/{id}` | Update task | Yes |
| DELETE | `/api/{user_id}/tasks/{id}` | Delete task | Yes |
| PATCH | `/api/{user_id}/tasks/{id}/complete` | Toggle complete | Yes |

See `contracts/openapi.yaml` for full API specification.

## Key Design Decisions

| Decision | Rationale | Reference |
|----------|-----------|-----------|
| User-scoped routes (`/api/{user_id}/tasks`) | Explicit ownership in URL aids debugging | research.md |
| JWT with 7-day expiry | Balances security with UX per spec | FR-006 |
| Pagination (50 items default) | Handles >1000 tasks edge case | research.md |
| Soft validation (no past due dates) | User flexibility per assumptions | Assumption 7 |
| Hard delete (no soft delete) | Simplicity; no recovery requirement | research.md |
